# トリミング君

画像やPDFの必要な部分を切り取り、保存するためのブラウザアプリです。

## 通信とプライバシーについて

**トリミング君は、PDFの読み込み・トリミングなどに使用するライブラリをCDNから取得するため、外部通信が発生します。完全オフライン対応ではありません。**

CDN通信はプログラム（PDF.js、jsPDF、JSZipなど）や画面表示用ライブラリを取得するためのもので、**選択した画像・PDFファイルそのものを外部サーバーへアップロードする処理は設けていません。** 写真やPDFの編集処理はブラウザ内で行います。

ただし、ライブラリ取得時には通常のWebアクセスと同様に、IPアドレスなどの通信情報がCDN事業者に伝わる可能性があります。初回利用時やキャッシュがない場合はインターネット接続が必要です。

## 使い方

1. アプリを開いて画像またはPDFを読み込みます。
2. 必要な部分を指定し、トリミングします。
3. 加工した画像やPDFを保存します。

## 利用上の注意

個人で制作した無料アプリです。すべての環境での動作を保証するものではありません。元のファイルを残し、書き出し結果を確認してご利用ください。インターネット接続を遮断した環境での正常動作は保証していません。
